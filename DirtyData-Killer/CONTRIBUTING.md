# 贡献指南

感谢愿意帮助「数据干净计划」的人！你不需要是 Python 高手，贡献一组**脱敏、最小复现的中文场景**就很有价值。

## 提交问题（Issue）

请尽量写清楚：

1. 发生在哪个平台 / 模型（如 WorkBuddy、ChatGPT、Claude、Cursor）；使用 Prompt 粘贴还是原生 Skill 导入。
2. 使用了哪一个 Skill、版本、输入格式（CSV/Excel/文字样本）。
3. 最小可复现数据（建议 3~10 行虚构记录）。
4. 实际输出与你预期结果的差异，尤其关注：虚构统计、行号不一致、危险的自动删除、前导零丢失。
5. 你希望怎样修复，或新的数据业务规则是什么。

不得包含手机号、身份证号、真实学号、用户隐私、token、客户名单或公司内部数据。

## 提交代码或 Prompt 更改

- Fork 并新建分支（如 `fix/audit-row-count`）。
- Prompt 改动：同步修改 `skills/<name>/SKILL.md` 和 `prompts/<name>.md`（后者只放正文），并补充 `examples/` 的期望输出。
- Python 改动：不要覆盖原始数据、不要默认删行；补充对应 `tests/`。
- 运行（可选）：`python -m unittest discover -s tests -v`。
- 提交 Pull Request 解释：为什么改、修改范围、哪些地方未实测。

## 提交前自检

- 无真实敏感数据 / 密钥。
- 不捏造“已运行成功”“平台已完全兼容”。
- 解释重大操作的回滚方案和风险。
- 中文术语尽量清楚，新手可读。

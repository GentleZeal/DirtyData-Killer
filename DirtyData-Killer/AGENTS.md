# DirtyData Killer 项目协作说明

本仓库的 Skill 是**中文指令模板**，不是生产级清洗服务。主要入口：`skills/`（结构化 SKILL.md）、`prompts/`（纯 Prompt）、`examples/`（虚构样本）、`docs/`（教程）。

代码助手协作时请遵循：

1. 诊断报告依据实际可获得的数据，明确是全量、样本还是描述；不虚构统计或“已执行”证据。
2. 默认保留原始数据、不自动删行、不丢失学号/订单号前导零；冲突或异常先标记。
3. 若改动 `skills/<name>/SKILL.md`，同步对应 `prompts/<name>.md` 与 `examples/` 的案例。
4. 跨平台使用说明要区别原生技能安装和粘贴 Prompt，注明资格/权限。
5. 实际修改参考脚本时维持独立输出目录和中文异常处理，必要时更新单元测试。
6. 不把敏感数据加入 Git 仓库或外发。
7. 不将未来 roadmap 的功能当成 v0.1.0 已实现。
